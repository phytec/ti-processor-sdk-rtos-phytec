Introduction

This section provides the performance numbers of MCAL Eth module.

Code Placement DDR
Data Placement DDR

Note:

  1. Throughput results are measured only at Layer 2(no user callback application is invoked when receive/transmit packet)
  2. Throughput results are measured using eth_app_cpuload example application built with the following modifications which are not the default optimization level:
    • eth_app_cpuload built with performance optimizations (OPTIMIZATION=PERFORMANCE passed to make command)
  3. Further performance improvements could be achieved by placing commonly used functions or data structures (such as packet descriptors or packet buffers) in faster memory, such as SRAM or OCMC. Note that the choice of memory to use is a system level decision as these memories may already be used for other purposes by other applications.

Host PC Command

  1. Build HostApp - This application is supported only in Linux
    • cd mcusdk_path/mcusw/mcal_drv/mcal/examples/Eth/eth_app_freertos/host/
    • make
  2. Run HostApp
    • ./EthHostAppCpuLoad -i ifname
