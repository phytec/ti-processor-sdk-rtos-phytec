This is an internal function that is used to determine which FFT kernel variant to call for optimal DFT computation.

Different kernel variants in this module implement DFT computation optimally for different FFT sizes and different batch sizes. This function is used to determine which kernel variant is optimal for a given FFT size and a batch size.

Parameters
[in]pKerInitArgs: Pointer to the structure holding init parameters
[in]MMA_SIZE: MMA vector width
[out]dftSmall: Parameter that takes values 1 or 0 depending on whether FFTLIB_FFT_dftSmall_ixX_cxX_oxX is the optimal kernel variant to use or not.
[out]dftLarge: Parameter that takes values 1 or 0 depending on whether FFTLIB_FFT_dftLarge_ixX_cxX_oxX is the optimal kernel variant to use or not.
[out]highRadixDecompositionsParameter that takes values 1 or 0 depending on whether FFTLIB_FFT_highRadixDecompositions_ixX_cxX_oxX is the optimal kernel variant to use or not.
Returns
void
